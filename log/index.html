What we've been shipping.

A short, dated record of the lab. Newest first, and everything links to the real thing.

August 27, 2026: The product upgrade, sealed

Rebuilt the site around what is actually live. A connectors section for the doors users already have (@emem in ChatGPT, the GitHub MCP Registry, VS Code, Claude, Dify), the satellite launch plan published as phases with deliberately no date, and the footer map replaced by the live memory itself: every dot a one-degree bin holding signed facts, straight from coverage_map.svg. The site now seals itself too: every served file is blake3-hashed into one release manifest whose CID sits in the footer, and every number we assert about emem lives in a facts registry with the live source that can refute it; CI turns red when the world moves and we have not.

August 2026: The memory grew devices, a front door for agents, and a guard

emem's token family is nine shapes now: emem:trace: (a verified OS execution trace of the machine that produced a reading) and emem:attestation: (a device's hardware root-of-trust evidence) joined the grammar, alongside the bare emem:cell: address. The substrate registry became a written admission contract: robots, drones, CCTV and industrial machines join only with their complete OS execution trace, verified against sixteen whitelisted hardware platforms. Agent-to-agent went live end to end: every tool is an A2A skill, runnable at POST /a2a/tasks, and the Agora opened as the collaborative channel where agents co-build on the memory, with a standard, a curriculum, a contacts registry and an inbox. And emem-guard shipped: an allow/deny verdict server for AI checkpoints, where a cited claim that stops verifying gets a denial with a machine-readable fix.

August 24, 2026: Listed where agents live

emem stopped being only an endpoint and became a listing: an app in ChatGPT you reach by mentioning @emem, an official entry in the GitHub MCP Registry with one-click install for Copilot and VS Code, a record in the official MCP registry, and a Dify marketplace plugin carrying every emem tool with no key to configure.

July 27, 2026: emem is the product

Rebuilt the site around the protocol itself. geo.qa now sits with eudr.dev and propcheck.dev as applications built on emem, and the home page shows the surface that actually ships: six token types, the witnessed transparency log, prediction, and every interface with full, copy-able URLs (pip, npm, MCP, REST, A2A).

July 26, 2026: Agents can find us on their own

Published the machine surfaces: an A2A agent card at /.well-known/agent-card.json, a guide for agents at agents.md, and a refreshed llms.txt. An agent that lands anywhere on vortx.ai can learn the protocol, run it, and route its human to the right session.

July 26, 2026: Founder time, priced honestly

Sessions went live end to end: free community office hours for anyone (students and early founders especially), and paid integration and sovereign sessions with checkout and calendar in one flow. The commitment is an exit criterion, not a guarantee: the session ends when recall runs and a receipt verifies in your stack.

July 26, 2026: The playground got real

The home-page playground now pulls three signed bands per click, straight from emem, and renders the cell's own latest Sentinel-2 scene inside the receipt. What you see is what the protocol returned, minutes ago.

June 18, 2026: A clearer vortx.ai

Relaunched the site around a single idea: one verifiable memory of Earth for AI agents. The home page now lets you pull a real signed fact for any place yourself.

June 15, 2026: The protocol, written up

Published the emem Earth-memory protocol on Zenodo: content-addressed records with signatures anyone can check offline. Both records are on the research page.

2026: TerraGround-Gemma, open-sourced

Released two LoRA fine-tunes of Gemma for grounding a language model in Earth observation, the 12B and the compact E2B, both on Hugging Face.

2026: emem.dev went live

Stood up the public, signed Earth-memory endpoint. No key, no account: ask by place, get a fact back with a receipt. Read it on the emem page.
