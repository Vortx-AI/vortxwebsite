An agent is only as good as what it remembers.

Put an agent in production and you'll watch it answer, with full confidence, about a place it knows nothing real about. Did this address flood. Did this farm get rain. It reaches for a bigger model; we think the gap is memory.

So we built the memory: one signed record of Earth, starting wherever a sensor already sits.

From a sensor to a fact your agent can cite.

Watch the world, remember it as a signed record, let anyone prove it.

01 Watch

Wherever a sensor already lives — satellites, drones, vehicle cameras, robots, fixed cameras — the world gets read right where it happens.

02 Remember

Every observation becomes a small, signed record, pinned to a patch of Earth about ten metres across — so any agent can find it again, and trust it.

03 Prove

Each fact carries proof of where it came from. An agent that quotes it hands you a receipt you can re-check yourself, offline.

Open · Apache-2.0

emem.dev

The open Earth memory protocol.

A public, signed layer of Earth memory any agent can read without an API contract. Run it yourself; the receipts still check out.

  • Free and open. Read it without a key, an account, or a contract.
  • Checkable offline. Every fact is signed, so you never have to trust the server.
  • Built on public satellite data. Open for anyone to read, run, or build on.

Private · Your tenancy

geo.qa

Earth memory that's yours, on your data.

For teams whose AI has to be right about specific places — pipelines, airports, ports, borders, fleets. The same protocol, fed by your own sensors, in a tenancy only your agents can read.

  • Your sensors, fused. Cameras, drones, satellites, sensors, files and maps, registered by location and view and segmented on demand.
  • A boundary that holds. Per-organisation scoping enforced in the code, on every read, not in a brochure.
  • emem underneath. Read the public layer, write your private one, cite both in one answer.
