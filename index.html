emem · Apache-2.0 changelog

“A model's memory ends where its context does. emem lives outside it: signed tokens that survive compaction, hand-offs and model swaps, so two agents that trust nothing else can cite the same fact. Apache-2.0. Earth first; every substrate, real or synthetic, maps back to it.”

An agent is only as good as what it remembers.

Put agents in production and you'll watch it happen: a session gets compacted and a verified fact becomes a paraphrase. A task hands off and the next agent starts from hearsay. Two models describe the same place and can't agree they mean the same thing. Everyone reaches for a bigger model; we think the gap is memory.

So we split the problem in two. Detectors write the evidence. emem holds it deterministically, as signed tokens any agent can decode back into its reasoning. Earth comes first because the sensors already sit there.

Substrates

One memory, many observers. Satellite observation anchors it today, and the live registry is a written admission contract per observer class: drones, robots, CCTV, telescopes, industrial machines join only with their device's complete OS execution trace. Synthetic substrates map back to Earth too.

Tokens

Nine token shapes, one syntax: facts, bundles, entities, cells, rasters, cubes, rastersets, and for devices, execution traces and hardware attestations. One handle, the exact bytes, months later.

Verification

Two agents that share no model, vendor, or trust cite the same token and each verify it alone, offline, with no server to trust.

The evidence half: our own satellite.

emem is the deterministic half, and today it holds evidence from public constellations. Our satellite is the evidence half built to match: traceable from photon to token, downlinked straight into the memory. Everything above this line is shipped. This section is the plan.

Fully traceable

Signed where it is sensed. Keys minted for the instrument itself, every frame signed at capture, so the chain from photon to fact CID has no unsigned hop anyone must take on faith.

Direct to emem

No data lake between orbit and answer. The downlink writes straight into the protocol: the moment an observation lands, it is a citable, signed fact with a receipt, not a file waiting in an archive.

Decentralised

What it sees lands in the witnessed, Merkle-proofed public log, and anyone can hold a copy. Verification never asks our permission, and nobody, including us, can quietly rewrite the record.

The deterministic half: external memory for multi-agent systems.

A public, signed memory that is itself an agent. Its deterministic surfaces (locate, recall, verify, diff) return the exact signed bytes for the same question, every time; its agentic surfaces (ask, reason, hunt, predict) plan and fan out under one signed receipt. Six token types, a witnessed transparency log. Run it yourself; the receipts still check out.

  • Free and open. Read it without a key, an account, or a contract.
  • Checkable offline. Every fact is signed and content-addressed, so you never have to trust the server.
  • Guarded. emem-guard, the allow/deny verdict server for AI checkpoints: a cited claim that stops verifying gets a denial with a machine-readable fix.
  • Every interface. MCP, REST, Python, TypeScript, and a live A2A endpoint where every tool is a skill.
