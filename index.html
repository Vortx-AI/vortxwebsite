An agent is only as good as what it remembers.

Put an agent in production and you'll watch it answer, with full confidence, about a place it knows nothing real about. Did this address flood. Did this farm get rain. It reaches for a bigger model; we think the gap is memory.

So we built the memory: one signed record of Earth, starting wherever a sensor already sits.

Substrates

Earth is the first substrate we fill. Nothing in the record is satellite-specific, so molecules, people, and signals write to the same loop next.

Tokens

Every observation is one signed, content-addressed token an agent can cite: facts, bundles, entities, rasters, cubes. One handle, the exact bytes, months later.

Verification

Two agents that share no model, vendor, or trust cite the same token and each verify it alone, offline, with no server to trust.
